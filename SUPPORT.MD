# Support & Community Resources for NOVA OS

Welcome to the NOVA OS support directory. If you encounter bugs, have feature requests, or need technical guidance, please refer to the resources below.

## 1. Issue Reporting

- **Bug Reports**: Open an issue on GitHub at [GitHub Issues](https://github.com/nived938/WEBOS/issues).
  - Include browser version, OS, and console logs.
- **Feature Requests**: Submit ideas via [GitHub Discussions](https://github.com/nived938/WEBOS/discussions).
