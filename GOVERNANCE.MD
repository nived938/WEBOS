# NOVA OS Project Governance

## 1. Project Mission

NOVA OS is an open-source, web-based operating system simulation platform developed to deliver an elegant desktop experience inside modern web browsers.

---

## 2. Roles & Responsibilities

- **Maintainers**: Core contributors responsible for reviewing pull requests, steering architectural decisions, managing releases, and maintaining repository security.
- **Contributors**: Community developers submitting bug fixes, applications, performance optimizations, and documentation.

---

## 3. Decision-Making & Voting

- Minor changes and bug fixes require approval from at least one core maintainer.
- Major architectural changes (e.g. state management revisions, core filesystem changes, window manager overhauls) require consensus or a majority vote among maintainers.
- Voting occurs asynchronously in GitHub Discussions or pull request threads, with a minimum review window of 72 hours.
